# Middleware

Middleware server project

## Run Project

Use Maven script, the server will run in local

```bash
mvn spring-boot:run
```

## Package Project

Use Maven script, the war file will be located at /target

```bash
mvn clean package
```

## Project dependency

- java 17
- spring-boot 2.7.18
- junit 5
- hibernate 5.6
- mysql 8
